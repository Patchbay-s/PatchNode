Guides et assistance

Les guides complets, avec commandes copiables et dépannage, sont intégrés à l’app : Réglages › Aide et support › Guides.

En résumé

Proxmox VE
Utilisateur et jeton API, rôle PVEAuditor sur / pour l’utilisateur et le jeton (Privilege Separation = intersection), rôle PatchNodePower (VM.PowerMgmt) pour les actions, toujours avec PVEAuditor sur les chemins sous / (une ACL plus précise remplace les rôles hérités, les invités disparaîtraient), reverse proxy avec le schéma https.
Proxmox Backup Server
Jeton utilisateur@realm!tokenid:secret (deux-points), rôle Audit sur /.
Docker
Jeton d’accès Portainer, ou tecnativa/docker-socket-proxy sans port publié, sur le réseau Docker du reverse proxy, POST=0, derrière une Access List avec mot de passe (Satisfy All). N’exposez jamais docker.sock.
Prometheus, Alertmanager
Pas de jeton : LAN/VPN uniquement, authentification Basic facultative via le reverse proxy.
Grafana
Service account avec le rôle Viewer et un jeton.
Uptime Kuma
Créez une page de statut et utilisez son URL terminée par /status/<slug>.
Tailscale
Settings › Trust credentials › client OAuth avec Devices › Core › Read ; pas les clés API.
CrowdSec
cscli bouncers add patchnode ; la Local API écoute sur 127.0.0.1 par défaut.
Nginx Proxy Manager
Utilisateur dédié avec View Only sur les Proxy Hosts.
AdGuard Home
Utilisateur dédié dans AdGuardHome.yaml (pas de rôle en lecture seule : LAN/VPN uniquement).
Home Assistant, Glances
Jeton longue durée d’un utilisateur non administrateur ; Glances en mode serveur web.

Questions fréquentes

Ça marche chez moi mais pas dehors.

PatchNode dialogue directement avec vos serveurs. Dehors, votre iPhone a besoin d’un VPN comme Tailscale ou WireGuard, et vos noms doivent être résolus à travers lui (split DNS).

Pourquoi HTTPS est-il obligatoire ?

Vos jetons voyagent avec chaque requête. Placez vos services derrière un reverse proxy avec un certificat valide (par exemple Let’s Encrypt avec un challenge DNS).

Un service est « en pause ».

Après un jeton refusé ou un blocage du reverse proxy, PatchNode cesse d’interroger pour ne jamais faire bannir votre IP par CrowdSec ou fail2ban. Mettez votre LAN et votre VPN en liste blanche de votre IPS.

J’ai perdu mon iPhone, ou un jeton a pu fuiter.

Révoquez les jetons sur chaque serveur, puis créez-en de nouveaux. PatchNode est verrouillé par Face ID ou votre code, mais seul un jeton révoqué protège à coup sûr. Préférez des jetons en lecture seule.

Recevez-vous des données ?

Non. Pas de compte, pas de statistiques d’usage, pas de serveur à nous. Seul un e-mail au support que vous choisissez d’envoyer nous parvient.

Puis-je essayer sans serveur ?

Oui : Réglages › Démo montre un HomeLab fictif complet généré sur l’iPhone.
