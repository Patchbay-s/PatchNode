En resumen

Proxmox VE
Usuario y token de API, rol PVEAuditor en / para el usuario y el token (Privilege Separation = intersección), rol PatchNodePower (VM.PowerMgmt) para las acciones, siempre con PVEAuditor en las rutas por debajo de / (una ACL más precisa sustituye los roles heredados y los invitados desaparecerían), proxy inverso con el esquema https.
Proxmox Backup Server
Token usuario@realm!tokenid:secreto (dos puntos), rol Audit en /.
Docker
Token de acceso de Portainer, o tecnativa/docker-socket-proxy sin puerto publicado, en la red Docker del proxy inverso, POST=0, detrás de una Access List con contraseña (Satisfy All). Nunca expongas docker.sock.
Prometheus, Alertmanager
Sin token: solo LAN/VPN, autenticación Basic opcional a través del proxy inverso.
Grafana
Service account con el rol Viewer y un token.
Uptime Kuma
Crea una página de estado y usa su URL terminada en /status/<slug>.
Tailscale
Settings › Trust credentials › cliente OAuth con Devices › Core › Read; no las claves de API.
CrowdSec
cscli bouncers add patchnode; la Local API escucha en 127.0.0.1 por defecto.
Nginx Proxy Manager
Usuario dedicado con View Only en Proxy Hosts.
AdGuard Home
Usuario dedicado en AdGuardHome.yaml (sin rol de solo lectura: solo LAN/VPN).
Home Assistant, Glances
Token de larga duración de un usuario no administrador; Glances en modo servidor web.

Preguntas frecuentes

Funciona en casa pero no fuera.

PatchNode habla directamente con tus servidores. Fuera de casa, tu iPhone necesita una VPN como Tailscale o WireGuard, y tus nombres deben resolverse a través de ella (DNS dividido).

¿Por qué es obligatorio HTTPS?

Tus tokens viajan con cada petición. Pon tus servicios detrás de un proxy inverso con un certificado válido (por ejemplo Let's Encrypt con un desafío DNS).

Un servicio aparece «en pausa».

Tras un token rechazado o un bloqueo del proxy inverso, PatchNode deja de consultar para que CrowdSec o fail2ban nunca bloqueen tu IP. Añade tu LAN y tu VPN a la lista de permitidos de tu IPS.

He perdido mi iPhone, o un token puede haberse filtrado.

Revoca los tokens en cada servidor y crea otros nuevos. PatchNode está bloqueado con Face ID o tu código, pero solo un token revocado protege con certeza. Prefiere tokens de solo lectura.

¿Recibís algún dato?

No. No hay cuenta, ni estadísticas de uso, ni servidor nuestro. Solo nos llega un correo al soporte que tú decidas enviar.

¿Puedo probarla sin servidor?

Sí: Ajustes › Demo muestra un HomeLab de ejemplo completo generado en el iPhone.
