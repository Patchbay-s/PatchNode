Anleitungen und Support

Die vollständigen Anleitungen mit kopierbaren Befehlen und Fehlerbehebung sind in die App integriert: Einstellungen › Hilfe und Support › Anleitungen.

Kurz gefasst

Proxmox VE
Benutzer und API-Token, Rolle PVEAuditor auf / für Benutzer und Token (Privilege Separation = Schnittmenge), Rolle PatchNodePower (VM.PowerMgmt) für Aktionen, auf Pfaden unterhalb von / immer zusammen mit PVEAuditor (eine genauere ACL ersetzt die geerbten Rollen, die Gäste würden verschwinden), Reverse Proxy mit dem Schema https.
Proxmox Backup Server
Token benutzer@realm!tokenid:geheimnis (Doppelpunkt), Rolle Audit auf /.
Docker
Portainer-Zugriffstoken oder tecnativa/docker-socket-proxy ohne veröffentlichten Port, im Docker-Netzwerk des Reverse Proxy, POST=0, hinter einer Access List mit Passwort (Satisfy All). docker.sock nie freigeben.
Prometheus, Alertmanager
Kein Token: nur LAN/VPN, optional Basic-Authentifizierung über den Reverse Proxy.
Grafana
Service Account mit der Rolle Viewer und einem Token.
Uptime Kuma
Erstelle eine Statusseite und nutze ihre URL, die auf /status/<slug> endet.
Tailscale
Settings › Trust credentials › OAuth-Client mit Devices › Core › Read; nicht die API-Schlüssel.
CrowdSec
cscli bouncers add patchnode; die Local API lauscht standardmäßig auf 127.0.0.1.
Nginx Proxy Manager
Eigener Benutzer mit View Only auf Proxy Hosts.
AdGuard Home
Eigener Benutzer in AdGuardHome.yaml (keine schreibgeschützte Rolle: nur LAN/VPN).
Home Assistant, Glances
Langlebiges Token eines Benutzers ohne Adminrechte; Glances im Webserver-Modus.

Häufige Fragen

Zu Hause klappt es, unterwegs nicht.

PatchNode spricht direkt mit deinen Servern. Unterwegs braucht dein iPhone ein VPN wie Tailscale oder WireGuard, und deine Namen müssen darüber aufgelöst werden (Split DNS).

Warum ist HTTPS Pflicht?

Deine Tokens werden mit jeder Anfrage übertragen. Stelle deine Dienste hinter einen Reverse Proxy mit gültigem Zertifikat (zum Beispiel Let's Encrypt mit DNS-Challenge).

Ein Dienst ist „pausiert“.

Nach einem abgelehnten Token oder einer Sperre durch den Reverse Proxy hört PatchNode auf zu fragen, damit CrowdSec oder fail2ban deine IP nie sperren. Setze dein LAN und dein VPN auf die Allowlist deines IPS.

Ich habe mein iPhone verloren, oder ein Token könnte offengelegt sein.

Widerrufe die Tokens auf jedem Server und erstelle neue. PatchNode ist mit Face ID oder deinem Code gesperrt, aber nur ein widerrufenes Token schützt sicher. Nutze bevorzugt schreibgeschützte Tokens.

Erhaltet ihr Daten?

Nein. Es gibt kein Konto, keine Nutzungsstatistiken und keinen eigenen Server. Nur eine Support-E-Mail, die du selbst sendest, erreicht uns.

Kann ich es ohne Server ausprobieren?

Ja: Einstellungen › Demo zeigt ein vollständiges Beispiel-HomeLab, das auf dem iPhone erzeugt wird.
