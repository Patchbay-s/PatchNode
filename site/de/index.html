Dein HomeLab auf einen Blick

PatchNode behält deine selbst gehosteten Server vom iPhone aus im Blick: Proxmox, Docker, Alarme, Backups, Netzwerk, Sicherheit und Hausautomation. Die App spricht direkt mit deinen Servern, über dein privates Netzwerk oder dein VPN.

Unterstützt: Proxmox VE, Proxmox Backup Server, Docker (Portainer oder ein schreibgeschützter Socket-Proxy), Prometheus, Alertmanager, Grafana, Uptime Kuma, Tailscale, CrowdSec, Nginx Proxy Manager, AdGuard Home, Home Assistant, Glances.

Konsolen, SSH und Compose

Öffne Proxmox-Konsolen, ein SSH-Terminal zu deinen eigenen Servern (Schlüssel auf dem Gerät erzeugt, Fingerabdrücke festgelegt) und verwalte Docker-Compose-Projekte, auf iPhone, iPad und Mac.

Privat von Grund auf

  • Kein Konto, keine Nutzungsstatistiken, keine Werbung, kein Tracking.
  • Tokens bleiben im Schlüsselbund des iPhone. Die Synchronisierung der Konfiguration oder der Tokens über den iCloud-Schlüsselbund ist optional und standardmäßig aus.
  • Nur HTTPS; Aktionen fragen immer nach Bestätigung und Face ID.

Ohne Server ausprobieren

Die integrierte Demo zeigt ein vollständiges Beispiel-HomeLab, das auf dem Gerät erzeugt wird.
