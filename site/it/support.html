Guide e assistenza

Le guide complete, con comandi copiabili e risoluzione dei problemi, sono integrate nell’app: Impostazioni › Aiuto e assistenza › Guide.

In sintesi

Proxmox VE
Utente e token API, ruolo PVEAuditor su / per l’utente e il token (Privilege Separation = intersezione), ruolo PatchNodePower (VM.PowerMgmt) per le azioni, sempre insieme a PVEAuditor sui percorsi sotto / (un’ACL più precisa sostituisce i ruoli ereditati, i guest sparirebbero), reverse proxy con lo schema https.
Proxmox Backup Server
Token utente@realm!tokenid:segreto (due punti), ruolo Audit su /.
Docker
Token di accesso Portainer, o tecnativa/docker-socket-proxy senza porta pubblicata, sulla rete Docker del reverse proxy, POST=0, dietro una Access List con password (Satisfy All). Non esporre mai docker.sock.
Prometheus, Alertmanager
Nessun token: solo LAN/VPN, autenticazione Basic facoltativa tramite il reverse proxy.
Grafana
Service account con il ruolo Viewer e un token.
Uptime Kuma
Crea una pagina di stato e usa il suo URL che termina con /status/<slug>.
Tailscale
Settings › Trust credentials › client OAuth con Devices › Core › Read; non le chiavi API.
CrowdSec
cscli bouncers add patchnode; la Local API ascolta su 127.0.0.1 per impostazione predefinita.
Nginx Proxy Manager
Utente dedicato con View Only su Proxy Hosts.
AdGuard Home
Utente dedicato in AdGuardHome.yaml (nessun ruolo in sola lettura: solo LAN/VPN).
Home Assistant, Glances
Token di lunga durata di un utente non amministratore; Glances in modalità server web.

Domande frequenti

Funziona a casa ma non fuori.

PatchNode comunica direttamente con i tuoi server. Fuori casa, il tuo iPhone ha bisogno di una VPN come Tailscale o WireGuard, e i tuoi nomi devono essere risolti attraverso di essa (split DNS).

Perché HTTPS è obbligatorio?

I tuoi token viaggiano con ogni richiesta. Metti i tuoi servizi dietro un reverse proxy con un certificato valido (per esempio Let's Encrypt con una challenge DNS).

Un servizio risulta «in pausa».

Dopo un token rifiutato o un blocco del reverse proxy, PatchNode smette di interrogare per non far mai bannare il tuo IP da CrowdSec o fail2ban. Metti la tua LAN e la tua VPN nella lista consentita del tuo IPS.

Ho perso l’iPhone, o un token potrebbe essere trapelato.

Revoca i token su ogni server, poi creane di nuovi. PatchNode è bloccato da Face ID o dal tuo codice, ma solo un token revocato protegge con certezza. Preferisci token in sola lettura.

Ricevete dei dati?

No. Nessun account, nessuna statistica d’uso, nessun nostro server. Ci arriva solo un’e-mail al supporto che scegli tu di inviare.

Posso provarla senza server?

Sì: Impostazioni › Demo mostra un HomeLab di esempio completo generato sull’iPhone.
