Il tuo HomeLab a colpo d’occhio

PatchNode tiene d’occhio i tuoi server self-hosted dal tuo iPhone: Proxmox, Docker, avvisi, backup, rete, sicurezza e domotica. Comunica direttamente con i tuoi server, tramite la tua rete privata o la tua VPN.

Supportati: Proxmox VE, Proxmox Backup Server, Docker (Portainer o un socket proxy in sola lettura), Prometheus, Alertmanager, Grafana, Uptime Kuma, Tailscale, CrowdSec, Nginx Proxy Manager, AdGuard Home, Home Assistant, Glances.

Console, SSH e Compose

Apri le console Proxmox, un terminale SSH verso i tuoi server (chiave creata sul dispositivo, impronte fissate) e gestisci i progetti Docker Compose, su iPhone, iPad e Mac.

Privato per progettazione

  • Nessun account, nessuna statistica d’uso, nessuna pubblicità, nessun tracciamento.
  • I token restano nel portachiavi dell’iPhone. La sincronizzazione della configurazione, o dei token tramite il Portachiavi iCloud, è facoltativa e disattivata per impostazione predefinita.
  • Solo HTTPS; le azioni chiedono sempre conferma e Face ID.

Provalo senza server

La demo integrata mostra un HomeLab di esempio completo, generato sul dispositivo.

Guide e assistenza · Informativa sulla privacy

PatchNode è indipendente e non è affiliata a Proxmox, Docker, Tailscale, Grafana né ai prodotti supportati. Nessun cookie né analisi d’uso su questo sito.
